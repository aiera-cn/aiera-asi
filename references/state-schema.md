# 读者存档(state-schema)

情报产品要像个认识你的人,就得记住你关心什么。存成本地 JSON,**跨会话可续**。

## 存哪
- `~/.aiera-asi/{handle}.json`,单人自用默认 handle = `me`
- 目录不存在就是新读者,**不要报错**;`Write` 时自动创建

## 什么时候读写
- **每次加载 skill**:先列目录 `~/.aiera-asi/`(用 `ls` 或 Glob,**别直接 Read 一个目录**),判断新读者/老读者
- **问完关注面、每次展开某块、读者明显对某方向来劲**:更新存档(整份覆盖即可,文件很小)
- 写之前先在脑子里合并旧值,别把已有的关注面覆盖没了

## 结构

```json
{
  "handle": "me",
  "context": "做 AI 内容/短视频的,自建 Obsidian 知识库跑精读流水线,关心 agent 落地与推理成本",
  "first_seen": "2026-09-10",
  "last_seen": "2026-09-10",
  "focus": ["模型与产品", "政策与安全"],
  "focus_official": ["模型与能力", "产品与生态", "政策与安全"],
  "interests": ["推理成本", "agent 落地"],
  "not_interested": ["资本与算力"],
  "last_briefed": { "date": "09/10", "time": "15:55" },
  "asked": [{ "q": "问过但没展开的", "when": "2026-09-10" }],
  "log": ["2026-09-10 首次,选了模型与产品+政策与安全"]
}
```

## 字段说明

| 字段 | 用途 |
|---|---|
| `context` | **他是干什么的**。从工作环境读出来(CLAUDE.md / MEMORY.md / 目录结构),一两句话。用来筛情报、讲"这条对你意味着什么"。⚠️ 只留本机,绝不外传 |
| `focus` | 读者选的**粗粒度**关注面(问他时给的那 4 个选项) |
| `focus_official` | 映射到新智元官方 5 分类,用于实际筛 `board` 的 `cat` 字段 |
| `interests` | 从对话里**观察**出来的更细方向,不是问出来的。他追问过什么、对什么来劲就记什么 |
| `not_interested` | 他明确说不关心的。下次别塞给他 |
| `last_briefed` | **上次给他看到哪条**。老读者回来时用它算"之后新增了多少条",这是情报产品最有用的一个字段。**"看到"包括一句话带过的**——你在"不在关注面但今天很热"里提了 08:37 那条,就推到 08:37,不是只算关注面内的最新条 |
| `asked` | 岔出去问过、当时没展开的,后面找机会补 |
| `log` | 一行一条流水,回归时一眼看懂上次到哪 |

## 粗粒度 → 官方分类的映射

问读者时用粗的(选项不能超过 4 个),筛数据时用官方的:

| 问他时说 | 实际筛 `board.category` |
|---|---|
| 模型与产品 | 模型与能力、产品与生态 |
| 公司与资本 | 资本与算力、组织与人事 |
| 政策与安全 | 政策与安全 |
| 全都要 | 不筛 |

⚠️ `feed`(秒追流)**没有分类字段**,只有 `board` 有。按 focus 筛 feed 时靠标题和摘要判断,并且**要告诉读者这是你归的类**,不是官方标的。

## 注意
- 这是**单机本地**存档,各人机器上各自的,互不干扰
- 只存"关心什么、看到哪",不存情报正文——情报每次实时取
- `context` 里只写**归纳出来的一两句话**,不要摘抄他文件里的原文,更不要存任何私密内容
