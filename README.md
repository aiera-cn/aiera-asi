# 新智元资讯秘书 · aiera-asi

把 [新智元](https://www.aiera.com.cn)(国内 AI 资讯头部媒体)变成你自己 AI 里的一个**资讯秘书**——认识你、记得你关心什么、替你筛当天的 AI 情报、陪你往下聊、每一步都递给你下一步。

不是资讯推荐器。推荐器是你问一句它吐一屏;秘书是它知道你是谁。

## 装

把这句话贴给你的 AI agent(Claude Code / Codex / Cursor 都行):

```
读 https://raw.githubusercontent.com/ThomasYin0216/aiera-asi/main/install.md,帮我装上
```

装完新开一个会话,说「今天 AI 圈有什么大事」。

**不想装?** 直接贴这句也能用:

```
读 https://raw.githubusercontent.com/ThomasYin0216/aiera-asi/main/SKILL.md,帮我盯新智元
```

## 它会做什么

- **第一次**:看一眼你的工作环境(项目说明、目录结构),知道你是干什么的;问一次你关心哪块——模型与产品 / 公司与资本 / 政策与安全 / 全都要——以后不再问
- **之后每次**:直接给你上次之后新增的,按你的关注面筛,带日期、带原文链接、带署名
- **随时追问**:这条什么意思、来龙去脉、对你的活儿意味着什么——事实和分析分开写,分析不挂新智元名下
- **每一轮**都递给你 2-4 个具体的下一步,可点选,不让你自己想下一句问什么

## 零 token · 零上传

新智元只出静态数据。推理、筛选、对话全在你自己的机器上,用的是你自己的 AI 额度——**新智元一分钱推理费不出,所以可以无限聊**。

你的关注面、阅读进度、工作环境画像,**全部只存在你本机的 `~/.aiera-asi/`**,不上传、不发给新智元、不写进任何请求。

## 数据来源

- **秒追 ASI**(滚动情报流)· **爆点榜**(24 小时热榜)· **ASI 启示录**(深度稿)
- 全部实时从 aiera.com.cn 取,不是模型记忆;取不到就说取不到,不编
- 每条带日期和原文链接;深度稿只给摘要,全文回官网看
