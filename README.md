# 元元 · 新智元十一年的化身

把 [新智元](https://www.aiera.com.cn)(国内 AI 资讯头部媒体,2015 年起)变成你自己 AI 里的一个**人**——她认识你、记得你关心什么、替你筛当天的 AI 情报、带着十一年的眼光讲给你听、陪你往下聊、每一步递给你下一步。

不是资讯推荐器。推荐器是你问一句它吐一屏;元元知道你是谁,而且六千多篇档案在她手里。

## 装

需要 **Claude Code 或 Codex**(命令行版,不是网页版)+ python3。把这句贴给它:

```
读 https://raw.githubusercontent.com/aiera-cn/aiera-asi/main/install.md,帮我装上
```

装完它会问你要不要现在试。说要。

**有 Claude Code 但不想装?** 贴这句免安装:

```
读 https://raw.githubusercontent.com/aiera-cn/aiera-asi/main/SKILL.md,你就是元元
```

**网页版**(ChatGPT / Kimi / 豆包 / claude.ai)在做,等官网静态目录上线。

## 她会做什么

- **第一次见面**:看一眼你的工作环境知道你是干什么的,先给你一口今天最有故事的一条,三句话说她是谁,然后按你的活儿推荐关注面——做内容的推有故事的,写代码的推能用的
- **之后每次**:不问,直接给上次之后新增的,而且有判断——"有一条你得看,不是因为热,是因为它动的是 X"
- **讲每一条分三层**:她报过的(档案事实,带链接)/ 她怎么看(每句判断挂一篇能查到的报道)/ 档案外的(框起来标"你要核")
- **十一年前传**:"这事之前报过吗"——她能翻到 2016 年,而且每句"我报过"都先查到再说
- **她也问你**:"你看这条注意到什么了?"你答了她接住、改路线
- **每轮递下一步**:可点的卡片,不让你自己想下一句问什么
- **不编**:取不到就说取不到;信源自己数字打架她标出来不圆场
- **自更新**:开场自己比对版本,落后就自己更

## 零 token · 零上传

新智元只出档案和规则(静态文件),**推理全在你自己的 AI 上**。新智元一分钱推理费不出,所以她可以慢慢陪你聊。你的关注面、画像、进度**全在你本机 `~/.aiera-asi/`**,不上传。

## 数据来源

**秒追 ASI**(滚动情报流)· **爆点榜**(24 小时热榜)· **ASI 启示录**(深度稿,只给摘要,全文回官网)· **六千多篇档案**(2015 年起,可按关键词和日期翻)。全部实时从 aiera.com.cn 取,不是模型记忆。
